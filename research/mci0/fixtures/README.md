# Independent original microfixtures

`cases.json` is authored before the parser. All strings are original synthetic
examples. Expected fractions are hand calculated from the frozen profile, never
generated by the parser. The test harness only projects actual IR for comparison.

Note rows: kind, location (`1` or `E1` or `C`), onset seconds, end seconds,
flags (concatenated b/x/f or empty), role (`O` ordinary / `H` slide head).
Slide rows: head note index, start lane, endpoint lane, shape, direction,
wait seconds, movement start, duration seconds, end seconds, track Break.
Null times mean unknown. Arrays are exhaustive, not selected matches.
Optional `facts` use dotted JSON paths for additional independently stated facts.
All diagnostics codes are exact sets unless a test specifically states otherwise.

Arithmetic examples: at 120 BPM `{4}` is 1/2 s; `{8}` is 1/4 s;
`[2:1]` is 1 s even across a later BPM change; short Hold is 1/640 s.
At 150.5 BPM `{3}` is 160/301 s. `[3##8:3]` waits 3 s then moves 3/4 s.
`[160#8:3]` waits 3/8 s then moves 9/16 s.
